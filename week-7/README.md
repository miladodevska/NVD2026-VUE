# BookNook — end of week 7

Week 7: The state of Vue and Pinia (Ch9 + Ch10). This folder holds the finished code for week 7 of the *Vue 3 in 7 Weeks — BookNook* curriculum. Students who missed the class can start week 8 from here (week 7 is the final app).

## Run it

```sh
npm install
npm run dev
```

Then open http://localhost:5173.

## Other scripts

```sh
npm run build    # production build into dist/
npm run preview  # serve the production build
```

Recommended: VS Code with the Vue (Official) extension, and the Vue DevTools browser extension.
