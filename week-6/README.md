# BookNook — end of week 6

Week 6: Routing (Ch7). This folder holds the finished code for week 6 of the *Vue 3 in 7 Weeks — BookNook* curriculum. Students who missed the class can start week 7 from here.

## Run it

```sh
npm install
npm run dev
```

Then open http://localhost:5173.

## Other scripts

```sh
npm run build    # production build into dist/
npm run preview  # serve the production build
```

Recommended: VS Code with the Vue (Official) extension, and the Vue DevTools browser extension.
